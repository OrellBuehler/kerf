Non-destructive · MCP-native · FFmpeg-backed

The video editor
your AI can drive.

Kerf is a cross-platform desktop video editor with an embedded MCP server, so an LLM can analyze your footage and assemble the cut through the same engine the GUI uses, on the same live project — and it can actually see the frames it edits. Nothing is re-encoded until you export.

The agent

Most tools bolt a chatbot onto an editor.
Kerf makes the editor an API.

The same Project is exposed twice — as the GUI you click and as Model Context Protocol tools an agent calls. It doesn't script a black box; it drives the identical engine — and its edits are staged for review, never applied behind your back.

👁

The agent has eyes

get_frame, skim_asset (a contact-sheet montage) and preview_timeline (the composited cut) return real images the model sees — so it finds the right moment and confirms the cut, not guesses from metadata.

🔗

Same engine, same project

The MCP server and the webview hold the same project behind one lock. No import/export round-trip, no second copy of the truth — and the agent previews its own work through the exact graph that renders your export.

📋

Staged, then reviewed

Agent edits build a proposal, not your cut. The review card shows a real diff — added, cut, moved, retrimmed — and you can watch the proposed timeline play, then apply all of it, tick only the changes you want, or discard it (and change your mind later). The agent can't switch review off for itself.

Built for finishing

Grade it, title it, and never lose it.

Kerf is more than a rough-cut tool: colour, motion graphics and a project file you can trust are all part of the editor — and the agent can use them too.

🎨

Grade with scopes

Shape a clip with RGB and luma curves, balance it with lift / gamma / gain wheels, or drop in a .cube LUT. Waveform, parade, histogram and vectorscope show what the frame really holds, measured on every pixel at full resolution, so you see clipping instead of guessing. An agent reads the same numbers with get_scopes.

✨

Motion templates

Build an animated title once — fade up, typewriter, lower third, or your own SVG — and save it as a .kerftemplate. Pick which parts stay editable (text, colour, number, font, image) and they become plain fields in the Inspector in any project. Fonts travel inside the template, so it looks the same on every machine.

🛟

Your work survives

An untitled project lives in a recovery file, so after a crash Kerf offers to bring it back. Save As writes a temp file and renames it over the target, so a failed save never eats the old one. A project from a newer Kerf is refused before anything is written, and a file is backed up before it is upgraded.

Connect any MCP client
and start editing.

The desktop app hosts the server over streamable HTTP on your own machine, behind a bearer token — Settings ▸ Agent shows it with the connect command filled in. Ask in plain language — “skim the interview, cut the dead air, drop in captions.” The agent sees your playhead and selection, runs long jobs in the background, and hands back a diff you review.

get_frame skim_asset preview_timeline analyze_asset cut_clip ripple_delete remove_silence snap_to_beats get_scopes set_grade apply_template generate_captions export_interchange staged_diff export +{{ sub $tools 15 }} more
connect with Claude Code
claude mcp add --transport http \
  kerf {{ $mcp }} \
  --header "Authorization: Bearer <token>"
…or any HTTP-capable client
{
  "mcpServers": {
    "kerf": {
      "type": "http",
      "url": "{{ $mcp }}",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}

Build from source

git clone {{ $gh }}
cd kerf/frontend && bun install && cd ..
cargo run -p kerf-app

Needs Rust ≥ 1.95, Bun ≥ 1.2, and (for media) the FFmpeg dev libraries. Builds without them via --no-default-features — the engine drives the ffmpeg / ffprobe binaries either way.

Then point an agent at it

claude mcp add --transport http \
  kerf {{ $mcp }} \
  --header "Authorization: Bearer <token>"

The app hosts the MCP server itself — there is no second process to start. Copy the command with your token from Settings ▸ Agent, queue a task in the agent panel, and review the diff it hands back.
